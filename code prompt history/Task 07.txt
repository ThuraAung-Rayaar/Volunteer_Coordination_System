      - Event actions (`event_delete`, `event_restore`, `event_cancel`) require `event`.
      - Feedback actions (`feedback_hide`) require `feedback`.
    - `ck_moderation_expiry`: Ensures `expires_at` is only populated when `action_type == 'user_block'`.
