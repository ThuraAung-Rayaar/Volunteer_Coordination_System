### 1. Implementation Details

#### [`apps/audit/services.py`](file:///c:/Users/USER/Documents/INTERN/Project/Volunteer%20HR%20Management/python%20stack/apps/audit/services.py)

- **`log_action(actor, action, entity_type, entity_id, before, after, ip, request) -> AuditLog`**:
  - Implements append-only audit tracking.
  - Automatically captures actor, IP address, and JSON before/after state diffs.
- **Admin Moderation Functions** (all guarded by `ensure_admin(admin)` and executed inside `transaction.atomic()`):
  - `warn_user(admin, target_user, reason)`: Records a `user_warning` moderation action and audit log.
  - `block_user(admin, target_user, reason, expires_at=None)`: Updates `account_status="blocked"` and `blocked_until=expires_at`, creates a `user_block` action, and logs before/after diffs.
  - `unblock_user(admin, target_user, reason)`: Resets `account_status="active"` and `blocked_until=None`, recording a `user_unblock` action.
  - `close_account(admin, target_user, reason)`: Sets `account_status="closed"`.
  - `reinstate_account(admin, target_user, reason)`: Restores `account_status="active"`.
  - `delete_event(admin, event, reason)`: Sets `deleted_at=timezone.now()` and `deleted_by=admin` (soft delete, hiding event from public and coordinator visible querysets).
  - `restore_event(admin, event, reason)`: Clears `deleted_at` and `deleted_by`.
  - `cancel_event_by_admin(admin, event, reason)`: Transitions event to `cancelled` and records an `event_cancel` moderation action.
  - `hide_feedback(admin, feedback, reason)`: Sets `feedback.status="hidden"`.
- **`dashboard_stats() -> dict`**:
  - Computes platform-wide aggregate statistics purely via Django ORM without raw SQL views:
    - User stats: `active_users`, `blocked_users`, `users_pending_verification`, `images_pending_review`, `coordinators_pending_approval`, `coordinators_approved`.
    - Event stats: `events_draft`, `events_published`, `events_active`, `events_completed`, `events_cancelled`, `events_deleted`.
    - Moderation stats: `warnings_last_30d`.
