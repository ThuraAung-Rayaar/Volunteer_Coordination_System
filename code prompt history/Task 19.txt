- `AdminWarnUserView` (`POST /api/v1/admin/users/{id}/warn/`): Calls `warn_user`.
- `AdminBlockUserView` (`POST /api/v1/admin/users/{id}/block/`): Calls `block_user`.
- `AdminUnblockUserView` (`POST /api/v1/admin/users/{id}/unblock/`): Calls `unblock_user`.
- `AdminCloseAccountView` (`POST /api/v1/admin/users/{id}/close/`): Calls `close_account`.
- `AdminReinstateAccountView` (`POST /api/v1/admin/users/{id}/reinstate/`): Calls `reinstate_account`.
- `AdminDeleteEventView` (`POST /api/v1/admin/events/{id}/delete/`): Calls `delete_event` (soft-delete).
- `AdminRestoreEventView` (`POST /api/v1/admin/events/{id}/restore/`): Calls `restore_event`.
- `AdminCancelEventView` (`POST /api/v1/admin/events/{id}/cancel/`): Calls `cancel_event_by_admin`.
- `AdminHideFeedbackView` (`POST /api/v1/admin/feedback/{id}/hide/`): Calls `hide_feedback`.
