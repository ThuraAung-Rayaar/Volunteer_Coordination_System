### 1. Implementation Details

#### [`apps/ops/serializers.py`](file:///c:/Users/USER/Documents/INTERN/Project/Volunteer%20HR%20Management/python%20stack/apps/ops/serializers.py)
- **`QrTokenSerializer`**: Metadata only; raw token hashes are excluded from public leakage.
- **`QrTokenGenerateSerializer`**: Validates `purpose` (`walkin_registration`, `checkin`, `join_event`), `max_uses`, and `ttl_minutes`.
- **`QrTokenResolveSerializer` & `QrTokenRedeemSerializer`**: Validates `token` string.
- **`AssignmentSerializer`**: Read-only representation exposing `event`, `post`, `user`, `group_code`, `is_group_leader`, `status`, and schedules.
- **`ManualAssignmentSerializer`**: Validates `application_id`, `post_id`, `group_code`, and `is_group_leader`.
- **`AssignmentCancelSerializer`**: Validates optional `reason`.
- **`AttendanceSerializer`**: Read-only attendance record (`status`, `checkin_at`, `checkout_at`, `method`, `note`).
- **`CheckInSerializer` & `CheckOutSerializer`**: Optional `user_id`, `method`, and `token`.
- **`MarkAbsentSerializer`**: Validates `user_id`.
- **`OnboardingAcknowledgmentSerializer` & `OnboardingAcknowledgeSerializer`**: Validates `method` (`app_tick`).
- **`FeedbackSerializer` & `FeedbackCreateSerializer`**: Validates `direction`, optional `target_user_id`, `score` (1..5), `tags`, and `comment`.

#### [`apps/ops/views.py`](file:///c:/Users/USER/Documents/INTERN/Project/Volunteer%20HR%20Management/python%20stack/apps/ops/views.py)
Thin `APIView` endpoints connecting requests strictly to `apps.ops.services`:
- `EventQrGenerateView` (`POST /api/v1/events/{id}/qr/`): Calls `generate_qr_token`.
- `QrResolveView` (`POST /api/v1/qr/resolve/`): Public preview calling `resolve_qr_token`.
- `QrRedeemView` (`POST /api/v1/qr/redeem/`): Authenticated redemption calling `redeem_qr_token`.
- `EventAutoRunAssignmentView` (`POST /api/v1/events/{id}/assignments/auto-run/`): Calls `run_auto_assignment`.
- `EventManualAssignmentView` (`POST /api/v1/events/{id}/assignments/manual/`): Calls `assign_manually`.
- `AssignmentConfirmView` (`POST /api/v1/assignments/{id}/confirm/`): Calls `confirm_assignment`.
- `AssignmentCancelView` (`POST /api/v1/assignments/{id}/cancel/`): Calls `cancel_assignment`.
- `EventCheckInView` (`POST /api/v1/events/{id}/check-in/`): Calls `check_in`.
- `EventCheckOutView` (`POST /api/v1/events/{id}/check-out/`): Calls `check_out`.
- `EventMarkAbsentView` (`POST /api/v1/events/{id}/mark-absent/`): Calls `mark_absent`.
- `EventOnboardingAcknowledgeView` (`POST /api/v1/events/{id}/onboarding/acknowledge/`): Calls `acknowledge_onboarding`.
- `EventFeedbackView` (`POST /api/v1/events/{id}/feedback/`): Calls `submit_feedback`.
- `MeApplicationsListView` (`GET /api/v1/me/applications/`): Returns only the authenticated user's applications.
- `MeAssignmentsListView` (`GET /api/v1/me/assignments/`): Returns only the authenticated user's assignments.
