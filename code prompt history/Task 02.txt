### Files Created & Configured

#### 1. [`apps/common/security.py`](file:///c:/Users/USER/Documents/INTERN/Project/Volunteer%20HR%20Management/python%20stack/apps/common/security.py)
- **`normalize_phone(raw_phone: str) -> str`**: Preserves leading `+`, removes all formatting characters, spaces, and hyphens.
- **`compute_phone_hash(raw_phone: str) -> str`**: Deterministic HMAC-SHA256 hex digest using `settings.PHONE_HASH_HMAC_SECRET` for phone identity indexing and query lookup without plaintext storage.
- **`encrypt_phone(raw_phone: str) -> str`**: Fernet symmetric encryption using key derived from SHA-256 of `PHONE_HASH_HMAC_SECRET`.
- **`decrypt_phone(encrypted_phone: str) -> str`**: Fernet decryption restoring the normalized phone string.
- **`generate_otp_code() -> str`**: 6-digit zero-padded cryptographic random string (`000000`–`999999`) using `secrets.randbelow`.
- **`hash_otp(raw_code: str) -> str`**: HMAC-SHA256 digest of the raw OTP code so plain codes are never stored in the database.
- **`generate_raw_token() -> str`**: Cryptographic URL-safe token using `secrets.token_urlsafe(32)`.
- **`hash_token(raw_token: str) -> str`**: SHA-256 hex digest for QR tokens and bearer tokens.

#### 2. [`apps/common/tests/test_security.py`](file:///c:/Users/USER/Documents/INTERN/Project/Volunteer%20HR%20Management/python%20stack/apps/common/tests/test_security.py)
