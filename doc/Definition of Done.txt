A module is complete only when:
1. Models match this reference.
2. Services implement the exact contract.
3. Views are thin.
4. Permissions are enforced in services.
5. Audit logs are written for state changes.
6. Tests pass.
7. No forbidden pattern is used.
8. API endpoints match the canonical API surface.
