## 6. API Integration
1. **`GET /api/v1/admin/audit-logs/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Query parameters for `user_id`, `action`, `target_type`, `limit`, `offset`. Returns list of audit entries (`AdminAuditLogSerializer`).
2. **`GET /api/v1/admin/audit-logs/{id}/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Detail view of single audit log record.
3. **`GET /api/v1/admin/geo-attempts/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Returns list of GPS check-in attempt telemetry (`AdminGeoAttemptSerializer`).
4. **`GET /api/v1/admin/feedback/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Returns flagged/active feedback for moderation queue (`AdminFeedbackSerializer`).
5. **`POST /api/v1/admin/feedback/{id}/hide/`**
   - **Method:** `POST` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Body `{"reason": "..."}`. Transitions feedback status to `hidden` and creates a moderation action log.
6. **`GET /api/v1/admin/actions/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Query parameters for `user_id`, `action_type`. Returns moderation action records.
7. **`POST /api/v1/admin/actions/`**
   - **Method:** `POST` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Body `{"target_user_id": int, "action": "...", "reason": "..."}`. Creates action; cascades account status to `blocked`/`suspended`.
8. **`GET /api/v1/admin/metrics/`**
   - **Method:** `GET` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Returns aggregate operational metrics (`AdminDashboardMetricsSerializer`).
9. **`POST /api/v1/admin/maintenance/run/`**
   - **Method:** `POST` | **Auth:** Bearer/Session | **Perms:** `is_super_admin=True`
   - **Behavior:** Runs background maintenance routines and returns summary of released blocks, purged tokens, and archived events.
10. **`POST /api/v1/events/{id}/feedback/`**
    - **Method:** `POST` | **Auth:** Bearer/Session | **Perms:** Authenticated
    - **Behavior:** Body `{"score": int, "comment": "...", "tags": [...]}`. Rejects if user attendance is not completed.
11. **`GET /api/v1/events/{id}/feedback/`**
    - **Method:** `GET` | **Auth:** None (AllowAny) | **Perms:** AllowAny
    - **Behavior:** Returns active, unhidden public reviews for an event.
