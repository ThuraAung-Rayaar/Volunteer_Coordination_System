## 5. SQL Integration

### SQL Functions & Procedures Verified
- `geo_check_in(p_event, p_user, p_lat, p_lon, p_accuracy_m, p_captured_at, p_is_mocked)`: Authoritative server-side geofencing and Haversine distance computation.
- `qr_token_status(p_token_hash)`: Non-destructive token validity inspection.
- `confirm_attendance(p_attendance, p_actor, p_note)`: Coordinator confirmation transition.

### SQL Triggers Verified
- `trg_01_audit_logs_append_only`: Strictly enforces append-only semantics on `audit_logs`, raising `append_only: audit_logs cannot be modified or deleted` on any `UPDATE` or `DELETE`.
- `trg_50_moderation_after_insert`: Automatically synchronizes `users.account_status` to `'blocked'` or `'suspended'` upon inserting a moderation action.
- `trg_events_after_update`: Automatically revokes active event QR tokens upon event completion or cancellation (`UPDATE qr_tokens SET revoked_at = now()`).
- `trg_events_before_update`: Restricts updates to owner, coordinator, or admin context.
- `trg_01_onboarding_before_insert`: Enforces `app_user_id() = NEW.user_id` on onboarding acknowledgments.
- `trg_01_attendance_guard`: Enforces strict attendance state machine (`expected -> checked_in -> completed`).

### Constraints Verified
- `ck_feedback_score`: Verifies score is an integer between 1 and 5.
- `ck_feedback_direction`: Verifies direction is in `('volunteer_to_event', 'coordinator_to_volunteer')`.
- `ck_qr_revoked`: Verifies `revoked_at IS NULL OR revoked_at >= created_at`.
- `ck_moderation_actions_action`: Verifies action is one of valid moderation action types.

## 6. API Integration

### Administrative & Governance Endpoints (`/api/v1/admin/`)
- `GET /api/v1/admin/audit-logs/`: List immutable audit logs with actor and target filtering.
- `GET /api/v1/admin/audit-logs/{id}/`: Detail view of a specific audit log record.
- `GET /api/v1/admin/geo-attempts/`: Review volunteer geofence check-in attempt telemetry.
- `GET /api/v1/admin/feedback/`: List flagged and active feedback for administrative review.
- `POST /api/v1/admin/feedback/{id}/hide/`: Hide violating feedback and record moderation action.
- `GET /api/v1/admin/actions/`: List moderation actions across users.
- `POST /api/v1/admin/actions/`: Issue administrative warning, suspension, or block.
- `GET /api/v1/admin/metrics/`: Aggregate administrative system metrics and counts.
- `POST /api/v1/admin/maintenance/run/`: Trigger automated maintenance routines.

### Feedback Endpoints (`/api/v1/events/{id}/feedback/`)
- `POST /api/v1/events/{id}/feedback/`: Volunteer submits rated feedback for a completed event.
- `GET /api/v1/events/{id}/feedback/`: List active, unhidden public feedback for an event.

## 8. Architecture Compliance

1. **Service Layer Isolation:**
   - Business operations reside strictly within service functions. Views and BFF layers remain thin dispatchers performing deserialization, permission checks, and response serialization.
2. **Database-First Integrity:**
   - Business rules, state machines, and immutability are rooted in PostgreSQL triggers, stored procedures, and check constraints without duplication or mock bypasses.
3. **Session Context & Audit Propagation:**
   - `set_db_session_context` and `set_system_actor_context` propagate the actor ID and client IP into database session variables, reliably restored in `finally:` blocks.
4. **Authentication & Authorization:**
   - Administrative endpoints strictly require `is_super_admin`, returning HTTP 403 for unauthorized users and HTTP 401 for unauthenticated requests.
5. **Concurrency & Transaction Boundaries:**
   - All mutating workflows are enclosed in explicit `@transaction.atomic` blocks. Tests requiring real transaction semantics run under `TransactionTestCase`.
6. **Privacy & Data Protection:**
   - Raw GPS fixes, device flags, internal moderation notes, and personal identifiers adhere strictly to tier masking and cannot be accessed from unauthorized volunteer endpoints.
7. **OpenAPI Schema Freeze:**
   - Generated using `drf-spectacular` with `--fail-on-warn` passing with 0 warnings and 0 errors.
